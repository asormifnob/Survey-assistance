SURVEY ASSISTANT - ANDROID COMPANION

This is a mobile-friendly web app source package, not an APK.

WHAT IT DOES
- Stores a user-entered survey answer profile in this browser on this phone.
- Lets you paste a survey question and search for a matching saved answer.
- Copies a suggested answer so you can paste it into a survey.

LIMITS
- It cannot read another Chrome tab or automatically fill other websites.
- It never submits surveys or bypasses CAPTCHA/screening.
- This version does not sync with the Windows extension or other devices.
- Data is stored in this browser's local storage. Clear the profile inside the app to erase it.

INSTALL
To install it like an app, these files must first be hosted at an HTTPS address. Then open that address in Chrome on Android, tap the three-dot menu, and choose Install app or Add to Home screen. The ZIP alone cannot be installed as an Android app.

Use a hosting provider you trust before entering personal information. The app has no analytics or remote database.
